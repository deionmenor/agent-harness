# Status

Maintained by the orchestrator. Under 20 lines. Read first every session.

Write this file before you hand back — at the end of a session, at the context limit, or when something blocks. It is the only thing a fresh session (or a different device) has to go on.

- **<date>: <one line on where things stand.>** <What landed since the last entry, with PR numbers.>
- **In review:** <PR numbers and what each one is.>
- **Blocked on <OWNER>:** <the decisions and actions that are only theirs.>
- **Blocked on the client/product:** <open questions and what they gate.>
- **Next:** <the single next task, and why it is next.>
- **Unverified:** <what nobody has seen run — on a device, in production, signed in. Say it plainly; a green build is not evidence.>
- **Bookkeeping:** <stray worktrees, branches to prune, records owed.>
- **Probes:** <the one command that reports true production status, if there is one. An ad-hoc request that follows redirects will lie to you.>
